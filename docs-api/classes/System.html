    Class SystemAbstract

    Abstract base class for ECS systems.

    Systems contain the logic that operates on entities with specific component signatures. Override update (and optionally fixedUpdate) to implement per-frame and fixed-timestep behaviour.

    Systems are sorted by priority — lower values run first.

    Example

    class MovementSystem extends System {
        readonly name = "movement";
        update(delta: number) {
            // move entities ...
        }
    }
