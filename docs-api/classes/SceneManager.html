    Class SceneManager

    Manages the lifecycle and active state of GameScene instances.

    Scenes are registered by key, set up asynchronously, and can be switched at runtime. Only one scene is "active" at a time; the active scene is rendered each frame by Game.

    Example

    await sceneManager.addScene("main", new MainScene(engine));
    await sceneManager.switchTo("main");
