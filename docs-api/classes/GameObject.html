    Class GameObjectAbstract

    Base class for all interactive objects in a GameScene.

    Subclasses implement onStart (called once after creation) and onUpdate (called every frame). Objects can be tagged for group queries and are automatically updated by their parent scene each frame.

    Example

    class Crate extends GameObject {
        onStart() { this.addTag("prop"); }
        onUpdate(dt: number) { /* rotate * / }
    }
