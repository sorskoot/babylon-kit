    Class DebugOverlay

    On-screen debug overlay that displays FPS, frame time, entity count, and frame number.

    Call init once to create the DOM element, then call update each frame while the overlay is enabled.

    Example

    const debug = new DebugOverlay();
    debug.init(engine);
    debug.enable();
    // in render loop:
    debug.update();
