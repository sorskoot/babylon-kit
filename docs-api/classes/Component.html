Class ComponentAbstract

Abstract base class for components.

Components are data containers that are attached to entities. Override the optional lifecycle hooks to react to attach/detach/update events; keep heavy logic in System implementations instead.

Example

class HealthComponent extends Component {
    current = 100;
    max = 100;

    onAdd() { console.log("Attached to", this.entity?.name); }
}
