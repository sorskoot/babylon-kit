    Class Game

    Root entry point for the game engine.

    Game owns the BabylonJS Engine and all top-level managers: SceneManager, AssetManager, UIManager, ParticleManager, AnimationManager, and AudioManager.

    Example

    const game = new Game("renderCanvas");
    await game.sceneManager.addScene("main", new MainScene(game.sceneManager.getEngine()));
    await game.sceneManager.switchTo("main");
    game.start();
