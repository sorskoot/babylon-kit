    Class InputSystem

    Unified keyboard, mouse, and gamepad input manager with an action-mapping layer.

    Register named actions with one or more bindings, then query action state each frame via isActionPressed, isActionHeld, isActionReleased, or getActionValue.

    Call attach once at startup to wire DOM events, and update at the start of each frame (before systems run) to advance the per-frame state.

    Example

    const input = new InputSystem();
    input.attach(canvas);
    input.registerAction({
        name: "jump",
        bindings: [{ type: "keyboard", code: "Space" }],
    });
    // in update loop:
    if (input.isActionPressed("jump")) { ... }
