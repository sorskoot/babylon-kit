    Class GameSceneAbstract

    Abstract base class for every scene in the game.

    A GameScene owns a BabylonJS Scene, a registry of GameObject instances, an InteractionManager, and an XRManager. Subclasses must implement setup to build the scene content and may override update for scene-level per-frame logic.

    Example

    class MainScene extends GameScene {
        async setup() {
            new ArcRotateCamera("cam", …, this.scene);
            new HemisphericLight("light", …, this.scene);
            this.addGameObject("player", new Player(this.scene));
        }
    }
