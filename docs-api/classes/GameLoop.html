    Class GameLoop

    Core game loop with a fixed-timestep accumulator and variable-rate updates.

    The loop does not manage its own requestAnimationFrame. Instead it is designed to be driven by an external frame source — typically Babylon.js's engine.runRenderLoop(). Call tick() once per frame from that external loop to advance game state.

    Raw delta is capped at 0.25 s to prevent spiral-of-death issues.

    Remarks

    Each call to tick() invokes up to three callback phases:

    1. fixedUpdate — zero or more times per frame, at a fixed interval.
    2. update — once per frame, with the variable (scaled) delta.
    3. render — once per frame, even while paused.

    Example

    const loop = new GameLoop(
        (dt) => updateSystems(dt),
        (dt) => stepPhysics(dt),
        ()   => scene.render(),
    );
    loop.start();

    // Drive from Babylon.js:
    babylonEngine.runRenderLoop(() => {
        loop.tick(performance.now());
    });
