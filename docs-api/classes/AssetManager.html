Class AssetManager

Asynchronous asset loading pipeline with caching, request deduplication, and manifest-based batch loading.

Register one or more loaders for specific file extensions, then load assets individually or via an AssetManifest.

Example

const assets = new AssetManager();
assets.registerLoader(new JsonLoader());
const data = await assets.load<Config>("config", "assets/config.json");
