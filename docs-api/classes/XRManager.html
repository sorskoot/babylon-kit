    initialize

    • initialize(options?: XRManagerOptions): Promise<WebXRDefaultExperience>

      Initialise the WebXR default experience. Call this after the scene's camera and environment are ready.

      Movement is configured via options.movement:

      • { mode: "teleportation", floorMeshes, ... } enables teleportation.
      • { mode: "locomotion", movementSpeed, ... } enables smooth locomotion.
      • If omitted, no movement feature is enabled.

      Parameters

      • options: XRManagerOptions = {}

      Returns Promise<WebXRDefaultExperience>
